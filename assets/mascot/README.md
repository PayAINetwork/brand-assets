# PayAI bot (mascot)

Status: proposed addition (November 2026). This doodle bot is a hand-drawn rendition of the friendly PayAI robot seen in PayAI social artwork, made for explainer videos and agent-made content. It complements the glossy 3D robot artwork; it does not replace it.

The PayAI Network mascot, ready for coding agents (Claude, Codex and others) and for people.

- **Agents:** point your agent at this folder. Codex reads `AGENTS.md`, Claude Code reads `CLAUDE.md`, and the folder
  is also a Claude skill (`SKILL.md`): copy it to `~/.claude/skills/payai-mascot/` or add it to a project.
- **People:** open `character-sheet/payai-bot-character-sheet.pdf`, or take images from `svg/` (vector) and `png/` (transparent).
- **New combinations:** open `generator/mascot.html?pose=wave&face=grin&role=CODEX` in a browser.

Contents: 16 faces, 24 poses, 10 emotes, 8 variants (role badges, hats, visor states, back view), the 6-page character
sheet, a generator and `mascot.json` (the index). Brand rules and the expression guide are in `AGENTS.md`.

The chest logo is the PayAI mark, unmodified. Use is governed by the repository `LICENSE`; see also
`THIRD_PARTY_NOTICES.md`. Reusable prompt: `prompts/mascot.md`.
